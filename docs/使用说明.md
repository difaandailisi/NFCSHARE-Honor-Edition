### 一碰传标签工具（荣耀优化版 v1.5.9）使用说明书

#### 1. 软件概述
- **软件名称**：一碰传标签工具（荣耀优化版 v1.5.9）
- **版本信息**：v1.5.9，此版本优化了蓝牙 MAC 读取逻辑。
- **软件用途**：该工具主要用于生成电脑和平板的一碰传标签二维码，同时提供了擦除手机标签记录、修复一碰传失效问题等功能，方便用户使用华为/荣耀设备的一碰传功能。

#### 2. 环境要求
- **操作系统**：Windows 系统（从代码中使用的 `wmic` 和 `ipconfig` 命令可判断）。
- **依赖工具**：ADB 工具（`adb.exe`），请将其放在程序同一目录或确保其在系统环境变量 `PATH` 中。

#### 3. 安装与配置
本程序无需安装，直接运行即可。确保 ADB 工具已正确配置，程序会自动查找 `adb.exe` 文件。
本程序，请直接管理员运行NFCSHARE程序。
请确保平板和手机的设备名称正确，如果不是原装名称，可能会匹配失败，请在此之前重置网络。

#### 4. 使用指南
如果手机是第一次运行NFCSHARE，第一次使用NFC贴纸，请直接运行选项5，不需要运行选项2
并且在贴纸制作完毕之后，使用NFC靠近贴纸时候，在平板显示第一次链接得同时，再使用第二次链接NFC才可以成功链接。
如果程序无法安装touchshare.apk(华为一碰传apk) nfctool.apk。请在手机上手动安装。

##### 主菜单介绍
运行程序后，会显示主菜单，包含以下功能选项：
1. 生成电脑一碰传标签
2. 擦除手机标签记录（含重启流程）
3. 修复一碰传失效问题
4. 仅清除手机标签记录（不擦除标签）
5. 生成平板一碰传标签

##### 操作流程

**生成电脑一碰传标签（选项 1）**
1. 选择此选项后，程序会自动获取电脑的 SN 和蓝牙 MAC 地址。如果自动获取失败，会提示用户手动输入。
2. 程序会生成一个包含 SN、MAC 和 MODELID 的代码，并根据此代码生成二维码。
3. 二维码会保存到程序根目录下的 `test.png` 文件中，并尝试自动打开。
4. 按回车键返回主菜单。

**擦除手机标签记录（含重启流程）（选项 2）**
1. 选择此选项后，会有警告提示，确认继续后，程序会禁用设备相关应用。
2. 手机会重启第一次，重启后连接电脑，按回车键继续。
3. 再次禁用设备相关应用，然后提示安装并启动 NFC Tool 用于擦除标签。
4. 标签擦除完成后，按回车键继续。
5. 询问是否制作新标签，选择 `y` 则会安装并启动一碰传助手，然后生成电脑一碰传标签；选择 `n` 则跳过此步骤。
6. 手机会重启第二次，重启后连接电脑，按回车键继续。
7. 程序会启用设备相关应用，操作完成后按回车键返回主菜单。

**修复一碰传失效问题（选项 3）**
1. 选择此选项后，提示连接手机，连接后按回车键继续。
2. 程序会启用设备相关应用，然后重启手机。
3. 手机重启后，按回车键继续，再次启用设备相关应用。
4. 修复完成后按回车键返回主菜单。

**仅清除手机标签记录（不擦除标签）（选项 4）**
1. 选择此选项后，程序会先禁用设备相关应用，然后再启用这些应用。
2. 记录清除完成后按回车键返回主菜单。

**生成平板一碰传标签（选项 5）**
1. 选择此选项后，程序会检查 ADB 连接，确保平板已正确连接并开启 USB 调试。
2. 自动获取平板的 SN、蓝牙 MAC 地址和协同码。如果自动获取失败，会提示用户手动输入。
3. 程序会生成一个包含 SN、MAC 和 MODELID 的代码，并根据此代码生成二维码。
4. 二维码会保存到程序根目录下的 `test.png` 文件中，并尝试自动打开。
5. 按回车键返回主菜单。

#### 5. 常见问题解答（FAQ）

**问题 1：找不到 `adb.exe` 文件怎么办？**
答：请将 ADB 工具放在程序同一目录，或者确保 `adb.exe` 在系统环境变量 `PATH` 中。

**问题 2：自动获取 SN 或蓝牙 MAC 地址失败怎么办？**
答：程序会提示用户手动输入，请按照提示输入正确的信息。

**问题 3：二维码保存失败怎么办？**
答：请确保程序目录可写入，或者手动检查目录权限。

| 平板型号 | 协同码 |

| M6 | 00005101 |
| MatePad | 00005103 |
| MatePad 10.8 | 00005105 |
| MatePad Pro | 00005107 |
| MatePad 11 | 00005108 |
| MatePad Air | 00005109 |

##### 荣耀平板
| 平板型号 | 协同码 |
| ---- | ---- |
| MagicPad2 | 00005177 |
| MagicPad 13 | 00005168 |
| MagicPad3 | 00005191 |
| Honor Pad V7 | 00005123 |
| Honor Pad V8 | 00005125 |

在生成平板一碰传标签时，程序会优先通过平板的型号匹配协同码，如果型号匹配失败，会尝试通过设备名称进行匹配。若双重匹配都失败，程序会提示用户手动输入协同码，并告知获取协同码的具体方法。
